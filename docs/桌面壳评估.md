# 桌面壳评估（V1.0 最后一项）

**结论（2026-11-13）：MVP/北极星不需要桌面壳；打包是分发阶段的事。当前形态 = 浏览器看板 + 手机审批 PWA + 聊天工具本体，已全部验收。**

## 本机事实

- Rust 工具链缺失（rustc/cargo 均不存在）→ **Tauri 当前不可构建**
- Electron 路线无外部依赖（Node 生态内，仓库有 Hermes Studio 先例）

## 两方案对比

| | Tauri | Electron |
|---|---|---|
| 产物体积 | ~5-10MB | ~150MB+ |
| 内存占用 | 低（系统 WebView） | 高（捆绑 Chromium） |
| 解除阻塞 | `winget install Rustlang.Rustup` 一次安装（约 10 分钟） | 立即可行 |
| 打包脚本 | cargo/tauri.conf.json + 前端指向 packages/server/public | electron-builder + 主进程 spawn `node packages/server` |
| 团队先例 | 无 | Hermes Studio |

## 实战记录（2026-11-14 夜，Tauri 路线推进到窗口创建一步）

Electron 脚手架已就位（packages/desktop/main.mjs：内核内嵌+窗口，正确代码）。首跑调试发现三层环境坑：
1. Electron 33 内嵌 Node 20 无 node:sqlite（内核存储依赖）→ 需 Electron 36+
2. Windows 下 electron postinstall 二进制下载需 ELECTRON_MIRROR=npmmirror
3. **段错误跨全部组合复现**：Electron 33/36 × 官方/镜像源 × 内嵌/spawn 双架构 × 带/不带 GPU 标志——定性为本机系统（Windows 内部版本 26300）与 Electron 打包 Chromium 的兼容问题，代码无关（spawn 架构 main 进程零内核导入仍崩）。⇒ **Tauri 被看好**：走系统自带 WebView2，完全绕开打包 Chromium；代价是需装 Rust（rustup 一次）。白天用户桌面机带显示调试 Electron 亦可再试（pnpm --filter @hive/desktop start）

## 剩最后一步（2026-11-14 03:00 止损）

Tauri 全套就绪：rustup 1.100 stable-msvc（系统本有 VS2022 Community）→ packages/desktop/src-tauri 编译成功（dev exe）→ server-child 子进程内核**在线实证**（/api/tasks 200）。唯一卡点：WebView2 窗口创建报 os error 5（拒绝访问）——需交互式桌面会话调试（WEBVIEW2_USER_DATA_FOLDER 指向 tmp 未解）。用户桌面跑一条命令验收：

```
cd packages/desktop && ./src-tauri/target/debug/hive-desktop.exe
```

【已解决】PowerShell Start-Process（交互桌面会话）启动验证成功：.board-url 生成 + /api/tasks 200 + 进程存活——**os error 5 是 bash 后台 Job Object 上下文特有**，交互会话中 Tauri 壳完全正常。桌面壳 ✅ 完成（Tauri 2.12.5 + WebView2，v0 窗口形态；tauri.conf bundle 打包安装器按需再开）。

## 解除阻塞路径（分发阶段再做）

1. **Electron 赶工线**（半天）：主进程 spawn HiveServer 子进程 → BrowserWindow 加载看板 → electron-builder 出 exe。托管凭据代理与 .env 同现状。
2. **Tauri 正式线**（1-2 天）：装 rustup → tauri.conf 指向 `http://127.0.0.1:<port>` 或内嵌静态页 + sidecar 起 node 服务。
3. 壳内安全不变：凭据代理 127.0.0.1 绑定、事件流审计、审批门全部在内核——壳只负责"装上像 App"。

## 与北极星的关系

北极星 TTFD ≤ 30 分钟的口径是「装上 → 聊天发一句话 → 交付」——聊天工具本身就是移动端入口，壳不参与验收路径。**桌面壳对北极星是零阻塞项。**
